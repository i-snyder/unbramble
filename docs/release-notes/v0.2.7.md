Deep transitive dependency queries now complete predictably on graphs with shared dependencies and cycles. Previously, these queries could consume CPU for minutes or longer while expanding duplicate routes through the same files.

## What's changed

- Fixed exponential route expansion in both `uses --transitive` and `who-uses --transitive`, including the depth-cap check.
- Preserved minimum-depth results, unresolved references, confidence labels, and the conservative `depth-truncated` warning for walks that reach the cap, including cycles.
- Added regression coverage for converging dependency routes with and without cycles in both directions, with a bounded work budget so a recurrence fails promptly.

Update with `unbramble update`, or follow the [manual ZIP update instructions](https://github.com/i-snyder/unbramble/blob/main/docs/installing.md#update-a-manual-installation). There are no command or index-format changes, and existing indexes don't need rebuilding.
