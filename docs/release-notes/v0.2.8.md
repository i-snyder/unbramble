Unity packages referenced through local `file:` folders now participate in the dependency graph, including packages outside the project and packages reached through junctions or symbolic links. Script GUIDs and asset references resolve through their `Packages/<name>/...` paths.

## What's changed

- Added local package discovery, reference parsing, and watcher coverage. Changes to package locations trigger reconciliation before queries can use the index.
- Fixed the paths used to read junction folders' own `.meta` files.
- Deferred automatic watcher startup until the triggering query has finished writing its output and released its index lease, reducing avoidable lock contention.
- Added explicit watcher phases for lock waits and indexing work. Progress messages report elapsed wait time without claiming that another process is making progress.

Update with `unbramble update`, or follow the [manual ZIP update instructions](https://github.com/i-snyder/unbramble/blob/main/docs/installing.md#update-a-manual-installation). Restart monitoring after replacing a manual installation. Existing indexes discover local packages automatically on the next query or watcher startup; the first reconciliation can take longer on large projects. No command or index-format changes are required.
