This release makes agent adoption more reliable and prevents project setup from assuming that every `.git` directory represents the project's active version-control system.

## What's changed

- Generated `AGENTS.md` guidance now makes UnBramble the default tool for reference, caller, dependency, and blast-radius questions. Text search remains appropriate for finding an unknown symbol name or unindexed literal content.
- The home status shows a prominent warning when a project's managed agent guidance is out of date. Run `unbramble init` after upgrading to refresh it.
- `unbramble init` now validates Git and Plastic SCM workspace markers instead of treating any `.git` entry as an active Git workspace.
- When both Git and Plastic SCM are valid, interactive setup asks which ignore files to update. Scripts and non-interactive sessions can select explicitly with `--vcs git|plastic|both|none`.

Existing projects should run `unbramble init` once after upgrading so their managed `AGENTS.md` block gets the new guidance.
