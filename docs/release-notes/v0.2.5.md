UnBramble is now available through WinGet, making installation and updates a one-command process while keeping the verified ZIP available for manual installs.

## What's changed

- The quick start now installs UnBramble with `winget install --id i-snyder.unbramble --exact`.
- The installation guide now covers WinGet upgrades and removal, with the manual ZIP workflow retained as an alternative.
- The maintainer release checklist now includes publishing and verifying each WinGet update.

There are no runtime or index-format changes in this release.
