Fixes C# type reference queries that missed a type when it was used to qualify a member, such as `Policy.Register()`. The first reference query after upgrading rebuilds the local index to recover those references.

Broad `resolve` searches now report when results were capped. Use `--limit N` to change the cap or `--all` to return every match.

Use `unbramble watcher-status --json` to check the background watcher without starting one or refreshing the index. Duplicate workers no longer publish a misleading stopped status, and activity recorded before startup no longer shortens a new watcher's idle window. Reference queries refresh the index as needed even when the watcher is absent. Start persistent watchers from a normal terminal when the command host may stop child processes on cancellation.

Windows binaries are rebuilt with the .NET 10.0.14 security fixes.
