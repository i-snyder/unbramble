UnBramble can now update a WinGet installation with one command, without requiring users to remember the underlying package-manager steps.

## What's changed

- Added `unbramble update`, which stops live UnBramble processes and opens the WinGet upgrade after the running CLI exits.
- Manual ZIP installations now receive clear, location-specific update instructions instead of an opaque WinGet error.
- Updated the README, installation guide, command help, and architecture notes for the new workflow.

There are no index-format changes in this release.
