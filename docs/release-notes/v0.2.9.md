Fixes missing C# references from predefined Unity assemblies to asmdef assemblies when generated project files use `ProjectReference`. Source dependencies now participate in analysis order and incremental/watch invalidation.

Project references to identity-only PackageCache dependencies now bind against their existing compiled package DLLs. Project regeneration and package DLL changes refresh analysis even when the caller's project file doesn't change.

Project scripts extending package assemblies through `.asmref` are analyzed with their package compilation context. Generated language versions and unsafe-code settings are honored, avoiding incorrect overload binding and false compiler diagnostics.

Unresolved member accesses are retained as speculative evidence. Semantic analyses with compiler errors report `cs-binding-incomplete`, and `stats` lists affected assemblies with error counts and codes. `dead-candidates` refuses deletion claims while these errors remain.

The first query after upgrading rebuilds the local index to recover references omitted by earlier versions. No Unity assets or source files are changed.
